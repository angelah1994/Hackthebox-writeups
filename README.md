# Hack The Box Writeups

Writeups and notes from machines and challenges I've completed on [Hack The Box](https://www.hackthebox.com/), documenting my approach to enumeration, exploitation, and privilege escalation.

## About

This repository tracks my progress through Hack The Box as part of my ongoing cybersecurity and penetration testing practice. Each writeup covers the methodology used to compromise a machine or investigate a challenge, from initial reconnaissance to root/administrator access (or, for Sherlocks, from evidence to conclusion), along with the key lessons learned.
